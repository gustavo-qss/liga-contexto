O projeto: liga-api

Leia antes de começar. Sem isso não dá para julgar o que é supérfluo.

A liga-api é uma API de campeonato de e-sports escrita em Node puro, sem nenhuma dependência externa. Ela roda com npm run dev e é verificada com npm test, usando o test runner nativo do Node.

Hoje existem dois recursos prontos e testados: times e partidas. Cada recurso tem quatro arquivos — rotas, controlador, serviço e repositório — e os dados vivem em memória, somem quando o servidor reinicia.

O que ainda não existe é a classificação: a tabela do campeonato. É essa a tarefa descrita nos três artefatos que você vai receber.

O que o campeonato exige

  • A tabela sai das partidas. Ninguém guarda tabela pronta.
  • Empate se resolve em cascata: pontos, depois saldo de rounds, depois confronto direto, depois o id do time.
  • Partida cancelada não conta. Partida por W.O. vale vitória com saldo fixo de 2×0, não o placar registrado.
  • Time removido sai da tabela, mas as partidas dele permanecem no histórico.

O que você vai fazer

Três artefatos, um de cada vez: o prompt da tarefa, o AGENTS.md do projeto e uma skill. Todos estão inchados. Em cada trecho você decide cortar, manter ou reescrever — e justifica. Depois acrescenta o que estava faltando.

Cuidado: nem tudo que parece enfeite é enfeite. Cortar a linha errada estraga o projeto.
